# Rebuttal code and circuits

This directory contains the four reproducible circuit and resource-estimation projects.
Each project retains its local tests, build files, caches, and small reference outputs so
that its documented commands remain self-contained.

- `binary_ecc_point_add_full_stream`: complete Python NCT streams for JSB25 FLT-in and FLT-out.
- `ac_balanced_dw_search`: C++ AC-arithmetic Balanced estimator and scans.
- `algorithm1_inplace_point_add`: in-place Algorithm 1 comparison with two inversions.
- `windowed_qrom_nct`: coherent QROM and windowed point-addition resource artifact.
